# ArchieNest 数字产品宣传册

基于 `PRD.md` 的首版可运行实现，包含公开画册、CMS、服务端会话、SQLite 数据、图片上传和询盘管理。无需安装第三方依赖。

## 本地启动

需要 Node.js 24 或更高版本。

```powershell
Copy-Item .env.example .env
# 编辑 .env，填写 ADMIN_PASSWORD
npm run dev
```

- 公开宣传册：http://localhost:3000
- 管理后台：http://localhost:3000/admin
- 默认用户名：`admin`，可在首次启动前通过 `ADMIN_USER` 修改。
- 如果未设置密码，首次启动会在终端显示一次随机管理员密码。密码使用 scrypt 哈希保存，不写入前端。
- 管理员在首次启动时创建，之后修改环境变量不会覆盖已有账号。请妥善保管密码。

## 使用流程

1. 后台「图片资源」上传图片，复制资源地址。浏览器会将图片缩小至最长边 1800px，并压缩为 WebP；原文件限制 5MB。
2. 「分类管理」维护分类及显示顺序，新增分类时自动创建对应画册页。
3. 「产品管理」录入名称、SKU、分类、主图和规格，可填写多张详情图。产品状态为 `published` 才会进入预览及发布版本；`draft` 和 `archived` 不公开。
4. 「宣传册页面」配置标题、正文、类型、关联分类及顺序。产品按排序数值排列。
5. 「品牌设置」修改封面标题、封面图和隐私说明。
6. 点击「预览草稿」查看效果，再点击「发布宣传册」。公开接口始终读取独立发布快照，编辑不会影响现有公开内容。
7. 客户提交询盘后，在「询盘管理」查看记录、维护联系状态。当前不发送邮件。

前台支持桌面双页、移动单页、方向键、按钮、滑动切页、分类目录、产品弹窗、图库、链接复制和产品查询参数深链接。动画可手动关闭并尊重系统减少动态效果设置。

## 数据与验证

- `data/catalog.sqlite`：草稿、发布快照、管理员哈希、会话及询盘。
- `data/uploads/`：上传的图片。
- 数据与 `.env` 均不进入 Git。备份时请停止服务并备份整个 `data` 目录。
- `npm test`：10 项服务端及阅读器测试，覆盖权限、草稿隔离、发布、软删除、分类隐藏、SKU 校验、询盘、图片管理和阅读器导航。
- `npm install` 后运行 `npm run test:browser`：使用本机 Edge 无头浏览器，检查 320 / 390 / 430 / 768 / 1280px 布局、翻页、触摸滑动、弹窗、询盘和减少动态效果设置。没有 Edge 时，可修改 `playwright.config.js` 的浏览器配置。
- `node scripts/generate-assets.mjs`：重新生成本地 SVG 示例插画。

## 实现选择与交付边界

当前使用原生浏览器 JavaScript / CSS + Node.js 内置 HTTP / SQLite，优先提供零依赖、可立即运行的业务闭环。PRD 的 Vue / FastAPI / PostgreSQL 为推荐方案，此版本未采用；后续规模化时可保留 API 契约迁移。

这是本地开发版本，尚未部署。示例产品、规格、MOQ 和 SVG 插画均为演示内容，应在正式发布前替换为品牌已确认且有权使用的资料。

当前翻页采用围绕书脊旋转的 3D 正反页、投影和方向区分；手机单页、桌面双页均支持翻页动效，可连续切页并清理中断动画。支持手机横滑，纵向滚动不会触发翻页。手机封面适应可视高度、底部翻页按钮保持可触达，弹窗与表单适配窄屏、安全区及横竖屏。尚未实现纸张曲面及跟随手指进度的物理翻书。三种产品模板仅提供基础展示差异，尚未达到完整杂志模板系统。页面目前通过分类关联产品，不支持任意指定多产品组合。

尚待生产化：PostgreSQL / 对象存储 / CDN、邮件通知、账号密码维护、按产品生成社交分享元数据、完整浏览器兼容及视觉验收。上传使用浏览器重编码和服务端文件签名校验，尚未增加服务端解码与像素上限检测。限流为单进程内存计数，适合当前本地开发；生产环境应由反向代理或共享存储承接。

如需部署，应将监听地址配置为所需网卡，在 HTTPS 反向代理后设置 `COOKIE_SECURE=true` 并保持正确 Host 及 Origin，不要直接将此开发服务暴露公网。当前默认仅监听 `127.0.0.1`。
